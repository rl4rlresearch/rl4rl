# Paper 5 Reproducibility Artifact

This archive reproduces the analysis for:

**The Interface Is the Instrument: How Autonomous-Research Scaffolds Change
Scientific Traces**

The artifact contains only already-recorded experiment logs, prompts, source
snapshots, and deterministic analysis code. It does not call a model provider,
launch a controller, train a candidate, or contact an evaluator.

## Contents

- `papers/aiscik2026/paper5/analysis.py`: the complete deterministic analysis.
- `papers/aiscik2026/paper5/derived/`: reproduced CSV, JSON, and figure
  outputs.
- `data/c0c3/...`: the analyzed run records, source snapshots, prompts, and
  event ledgers for the selected horizons.
- `data/c0c3/*/inputs/{framework,protocol,task}.json`: frozen campaign
  configuration records, including requested subject model, reasoning effort,
  service tier, conversation mode, task, and framework metadata.
- `PAPER5_SHA256SUMS`: SHA-256 checksums for every packaged payload file.
- `LICENSE`: MIT license for the packaged artifact payload.

## Analyzed strata

The main same-task comparison is Fashion-MNIST:

- `fashion-mnist-autoresearch-v1-7-mps-campaign`, blocks 1--4, C0--C3,
  first 44 proposals per trajectory.
- `fashion-mnist-openevolve-v2-1-mps-campaign`, blocks 1--4, C0--C3,
  first 44 proposals per trajectory.

Two extensions test whether the interface findings depend on a single task or
on a single OpenEvolve wrapper:

- nanoGPT: Autoresearch versus bounded greedy OpenEvolve, blocks 1--3, first
  five proposals per trajectory.
- Tiny Addition: bounded greedy OpenEvolve versus native-population OpenEvolve,
  blocks 1--8, first 70 proposals per trajectory.

Horizons are right-censored common prefixes. The trajectory/block-condition
pair is the replication unit; proposal-level observations describe process
measurements inside trajectories and are not treated as independent
replications.

## Reproduction

From the unpacked archive root:

```bash
shasum -a 256 -c PAPER5_SHA256SUMS
python3 -m venv .venv
.venv/bin/python -m pip install -r papers/aiscik2026/paper5/requirements.txt
.venv/bin/python papers/aiscik2026/paper5/analysis.py --data-root . --verify-input-hashes
```

`PAPER5_SHA256SUMS` verifies the packaged payload as released. Run it before
regenerating derived outputs, because Matplotlib-rendered figure files may
include renderer-dependent metadata. The `--verify-input-hashes` gate checks
the raw inputs against the frozen input ledger before writing derived outputs.
The numerical CSV/JSON outputs are deterministic under the included script,
which uses fixed bootstrap seed `20260902`.

## Claim boundary

The paper analyzes recorded autonomous-research traces as interfaces for
scientific work. It does not claim to observe private chain-of-thought. Textual
measures use recorded final proposal summaries, visible prompts, and stored
event metadata. Fashion-MNIST is the primary same-task contrast; nanoGPT and
Tiny Addition are stress checks with narrower identification.

The comparisons are descriptive and interface-composed. They are not randomized
estimates of an underlying model capability, and the same LLM family can behave
as different research systems when the controller, memory surface, patch
contract, parent sampling, and logging schema change.

All analyzed campaign protocol files request `gpt-5.6-sol` with `xhigh`
reasoning effort. Fashion-MNIST and nanoGPT protocol files record
`service_tier=fast`; Tiny Addition protocol files record
`service_tier=default`. These are requested configuration records rather than
provider-side attestations. Proposal event files separately record realized
token usage and per-event service-tier fields.

The packaged numerical CSV/JSON outputs are deterministic when the analysis is
rerun into a fresh output directory. Figure files are regenerated by
Matplotlib and should be treated as rendered artifacts rather than byte-stable
scientific inputs.
