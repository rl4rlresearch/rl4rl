# Patch format

Return the required `MECHANISM`, `HYPOTHESIS`, `INTENDED_EDIT`, and `EVIDENCE`
lines, followed by one or more exact blocks in this format:

{search_marker}
exact existing lines
{divider_marker}
replacement lines

Every `SEARCH` section must be nonempty and match exactly once in the current
implementation after earlier blocks have been applied. All blocks must apply.
They may edit either or both editable files, but together they must describe
one implementation ready for verification. Do not include a second alternative
or a full-file rewrite when a targeted patch is sufficient.
