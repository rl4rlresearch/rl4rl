# Trajectory Dashboard Design Brief

- Audience: researchers comparing architecture-search process dynamics across frameworks, horizons, memory policies, and assumption-challenge interventions.
- Primary task: see when each run discovers a smaller structurally valid architecture, then inspect the proposal that caused the change.
- Visual direction: compact dark research interface based on the supplied trajectory screenshot; neutral charcoal surfaces, crisp off-white type, restrained multicolor run lines, and no gradients or glow.
- Information hierarchy: filters and run toggles, then the parameter trajectory, then proposal-level evidence.
- Interaction: immediate filtering, click-to-toggle runs, keyboard-visible focus, and useful point labels.
- Layout: one continuous analysis surface with 8px panels, 24px spacing, thin borders, and a readable mobile stack.
